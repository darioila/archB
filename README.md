# archB
archB is a Blender add-on designed for 2D CAD drafting and 3D architectural modeling.

The idea behind this plugin stemmed partly from a challenge: to enable people with little to no 3D graphics experience to model architecture within a highly complex program like Blender.

The plugin doesn't perform tasks that Blender cannot already handle; rather, it simplifies the process. The geometry it generates integrates seamlessly with Blender's native geometry, allowing it to be modified using the program's standard commands.

I hope you enjoy the plugin and find it as easy to use as I intended.
